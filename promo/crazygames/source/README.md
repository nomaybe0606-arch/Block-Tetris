# Original Grid Pulse artwork sources

The three original PNGs in this directory were created for this project with the built-in imagegen tool on 2026-11-02. They are retained as the editable/recomposition masters, not included in the game ZIP. No external game art, platform marks or stock images were supplied. Purely AI-generated material is not asserted to have exclusive copyright where that is not recognized.

Shared generation brief: premium original casual block puzzle key art; saturated midnight indigo/navy background, cyan-violet light ribbons, recognizable square beveled rounded Neon Glass blocks in cyan, amethyst, gold, pink and mint; tilted 8×8 board, a cyan completed-line pulse and restrained sparks, chunky connected foreground shapes with motion trails. Large legible white/cyan title, exactly “Grid Pulse”, as the only text. No frames, watermarks, platform marks, slogans, UI screenshots or falling tower. Landscape: title on left and board on right. Portrait: two-line title above board. Square: title at top, board below.

Requested aspect ratios: landscape 16:9, portrait 2:3, square 1:1. The tool returned original masters at 1672×941, 1024×1536 and 1254×1254. `node scripts/prepare-crazygames-covers.mjs` normalizes them to the exact portal dimensions with FFmpeg Lanczos scaling. No generated pixels are used in game mechanics or in recorded gameplay; video shows the cover for 0.12 s then crossfades by 0.55 s to genuine Phaser rendering.

Re-record video: `node scripts/promo-crazygames-server.mjs`, open http://127.0.0.1:5174/promo.html and click each Record button, keeping the tab active for 18 s. The separate DEV entry reuses GameScene, DragController, placePiece and all real clear/combo effects. Only the initial mid-game fixture and synthetic pointer-capture handshake are prepared for QA. Six legal placements run in real time; subsequent shapes come from the unchanged generator. Canvas MediaRecorder captures the actual Phaser postrender output at 30 fps, composited with the live score and title for each aspect ratio. No cursor or audio track is captured. Run `node scripts/finalize-crazygames-video.mjs` to encode MP4/H.264/yuv420p with unchanged playback speed, then `npm run verify:promo:crazygames`.

The recording receiver accepts only named local artifacts and is never part of any production server/build. Raw WebM files and capture reports are ignored under artifacts/crazygames-capture/; final MP4s and validation.json are retained under promo/crazygames/.
